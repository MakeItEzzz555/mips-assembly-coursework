# MIPS Assembly Coursework

Three independent Frederick University computer-architecture labs using MIPS assembly, registers, byte/word buffers, loops and simulator syscalls. Nearby architecture-course material establishes the context; a precise module code is not established.

## Run

Use a MIPS teaching simulator with pseudo-instructions and the SPIM/MARS-style print/read/exit syscalls. Load one file at a time, assemble it, and run its `main` entry. The original files are `lab6/lab6.txt`, `lab7/acoeLab7.asm` and `lab8/lab8.txt`; if the file chooser filters extensions, select all files. Lab 8 prompts for ten integers. These files are simulator programs, not native macOS executables.
